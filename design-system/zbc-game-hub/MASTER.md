# ZBC Game Hub 设计系统

本文件是网站视觉与交互的全局准则。页面级规范如存在，放在 `pages/` 下并覆盖对应条目。

## 设计方向

- 产品定位：中文游戏资源目录，不是营销落地页。
- 视觉关键词：浅色、紧凑、可信、内容优先、易扫描。
- 信息密度：高；依靠清晰分组和留白层级保证可读性。
- 禁止项：大面积暗色、霓虹发光、装饰渐变、玻璃拟态、过度圆角、无意义动效和夸张营销文案。

## 色彩

| 用途 | 色值 |
| --- | --- |
| 页面背景 | `#f5f6f8` |
| 卡片与主要表面 | `#ffffff` |
| 主文字 | `#17181c` |
| 次文字 | `#666a73` |
| 边框 | `#e5e6eb` |
| 主品牌紫 | `#6d4aff` |
| 主品牌悬停 | `#5b39ed` |
| 浅紫底 | `#f1edff` |
| 状态橙 | `#f28c28` |
| 错误红 | `#d83b3b` |

紫色只用于导航状态、链接和主操作，不作为大面积装饰背景。正文与背景必须满足 WCAG AA 对比度。

## 字体与排版

- 字体栈：系统中文无衬线字体；不加载第三方网页字体。
- 正文字号：桌面端 `14–16px`，移动端表单正文不低于 `16px`。
- 行高：正文 `1.65–1.8`，标题 `1.25–1.4`。
- 标题使用字重和间距建立层级，不使用超大字号制造视觉冲击。
- 长正文限制行宽，游戏元数据使用固定标签和紧凑网格。

## 布局与间距

- 最大内容宽度：`1200px`，两侧使用自适应安全边距。
- 采用 `4/8px` 间距节奏；常用间距为 `8 / 12 / 16 / 24 / 32px`。
- 桌面端优先展示内容网格与排行榜侧栏；移动端自然降为单列。
- 断点围绕 `1180 / 1020 / 760 / 560 / 380px` 处理，不允许横向溢出。
- 卡片圆角以 `6–8px` 为主；模态框可使用 `10–12px`。

## 组件

### 顶部导航

- 白底、细边框、紧凑高度；一级分类始终清晰可见。
- 当前页面使用紫色文字与浅紫背景表达，不能只靠颜色以外缺少文本语义。
- 搜索框是主要工具，不使用占据首屏的大型营销 Hero。

### 游戏卡片

- 使用真实横版宣传图，固定宽高比并预留空间，避免布局跳动。
- 标题、平台、类型、体积、更新时间按稳定顺序排列。
- 悬停仅调整边框、阴影或颜色，不缩放造成布局或视觉抖动。

### 按钮与表单

- 主按钮使用品牌紫；次按钮使用白底边框。
- 所有图标按钮提供可访问名称；输入框使用可见标签或关联的 `aria-label`。
- 交互区域至少 `44×44px`；异步提交显示处理中状态并禁止重复提交。
- 键盘焦点使用清晰的紫色轮廓，不移除浏览器可访问性提示。

### 弹窗

- 遮罩使用足够不透明度隔离背景；关闭按钮和 Esc 键均可退出。
- 下载来源按稳定列表排列，推荐项用文字标签说明，不只靠颜色。
- `z-index` 由弹窗容器统一管理，避免跨层叠上下文竞争。

## 图片、图标与动效

- 游戏封面由 `next/image` 输出，首屏重点图可预加载，其余延迟加载。
- 图标统一使用同一套线性 SVG 语言，不使用 emoji 充当结构图标。
- 动效限于 `150–250ms` 的状态反馈，不使用循环装饰动画。
- 必须尊重 `prefers-reduced-motion`，在该模式下关闭非必要过渡。

## 交付检查

- 桌面 `1440px`、手机 `375px`、横屏 `844px` 均无横向滚动。
- 每页只有一个主标题，标题层级顺序正确。
- 图片具有准确替代文本，表单和按钮可通过键盘操作。
- 浅色模式下正文、边框、焦点和错误状态均清晰可辨。
- 首屏无装饰性加载等待，图片尺寸已预留，导航和主要操作触达稳定。
