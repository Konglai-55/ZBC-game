# ZBC Game 游戏资源站

Next.js 全栈游戏资源门户，包含前台分类、搜索、详情下载、帮助中心和管理员后台。

## 启动

```bash
pnpm install
pnpm dev
```

开发环境地址：`http://localhost:3000`

后台地址：`http://localhost:3000/admin/login`

开发和生产环境都必须在 `.env.local` 或部署平台环境变量中设置 `ADMIN_USERNAME`、`ADMIN_PASSWORD`、`ADMIN_SESSION_SECRET`。程序不提供默认管理员密码。

## 后台能力

- 游戏：新增、编辑、删除、封面上传、PC 系统配置、各网盘二维码线路与提取码
- 资源：MOD、修改器、工具、补丁的新增、编辑、删除、发布状态、附件和外链
- 教程：六个平台帮助文章的新增、编辑、删除和发布状态
- 反馈：查看文字与截图，按日期、类型和状态筛选，批量标记并回填说明；答复游戏评论后自动置顶到 FAQ
- 文件库：按游戏和用途归档，搜索、查看未引用图片、批量移入回收站，并在恢复或彻底删除前检查引用
- 设置：站点名称、公告、联系邮箱和侵权投诉邮箱
- 站点文书：编辑关于我们、侵权处理与版权声明，支持发布状态和格式化正文

内容数据写入 `data/*.json`。图片上传至对象存储，前台由站内 /media/ 路由签发有效期十分钟的读取链接，图片限制为 5 MB；普通附件写入 `public/uploads/`，限制为 128 MB。

## 生产部署提示

当前数据层使用本地 JSON 文件，适合单机部署或原型验证。多实例、容器或云部署时，应将 `lib/content-store.ts` 替换为数据库/对象存储实现，并配置持久化卷；管理员会话使用 HttpOnly、SameSite=Strict 的签名 Cookie。

## 后台安全与存储

管理员可在「站点设置 → 双重验证」绑定验证器。也支持通过 ADMIN_TOTP_SECRET 配置 Base32 密钥。启用后需要密码和六位动态码，旧的单因素会话失效。连续失败八次触发十五分钟窗口的账号限制，状态存放在持久化 data 目录。回收站与操作日志位于 /admin/history。

生产环境应持续挂载原有 data 和 public/uploads。回收站中的游戏、资源、教程和反馈在原文件内保留内容及删除标记，已回收文件保留对象直至管理员确认彻底删除。回滚代码前需确认目标版本能够识别删除标记。

既有 OSS 图片地址在展示时经站内签名入口转换。先验证站点的对象存储凭据可读取实际封面、二维码，再在存储服务收紧匿名 GetObject 权限，并核验站内图片可以加载且原始地址拒绝匿名访问。未完成桶端切换之前，既有公开链接仍可使用。

下载入口访问量从启用新版本时按访客点击累计；同款游戏同一浏览器在北京时间同一天只计一次。PC、安卓等更新数按北京时间自然周、自然月内更新的不同游戏计算。只有日期的历史数据按月日显示。
