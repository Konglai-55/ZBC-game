# ZBC Game 游戏资源站

Next.js 全栈游戏资源门户，包含前台分类、搜索、详情下载、帮助中心和管理员后台。

## 启动

```bash
pnpm install
pnpm dev
```

开发环境地址：`http://localhost:3000`

后台地址：`http://localhost:3000/admin/login`

开发和生产环境都必须在 `.env.local` 或部署平台环境变量中设置 `ADMIN_USERNAME`、`ADMIN_PASSWORD`、`ADMIN_SESSION_SECRET`。程序不提供默认管理员密码；当前本机开发凭据已经随机生成在 `.env.local` 中。

## 后台能力

- 游戏：新增、编辑、删除、封面上传、PC 系统配置、各网盘二维码线路与提取码
- 资源：MOD、修改器、工具、补丁的新增、编辑、删除、发布状态、附件和外链
- 教程：六个平台帮助文章的新增、编辑、删除和发布状态
- 反馈：催更/报错查看、标记处理、重新打开和删除
- 文件库：图片、压缩包、文档上传、预览/下载和删除
- 设置：站点名称、公告、联系邮箱和侵权投诉邮箱
- 站点文书：编辑关于我们、侵权处理与版权声明，支持发布状态和格式化正文

内容数据写入 `data/*.json`。图片上传至对象存储并由外链直接提供，图片限制为 5 MB；普通附件写入 `public/uploads/`，限制为 128 MB。

## 生产部署提示

当前数据层使用本地 JSON 文件，适合单机部署或原型验证。多实例、容器或云部署时，应将 `lib/content-store.ts` 替换为数据库/对象存储实现，并配置持久化卷；管理员会话使用 HttpOnly、SameSite=Strict 的签名 Cookie。
